# Arena de Votos — Sistema de Coleta e Análise de Dados

Aplicação web full stack desenvolvida para atender a uma demanda profissional, a pedido de um assessor, com o objetivo de apoiar a coleta de votos e a análise de dados de votação.

O sistema utiliza uma interface interativa de duelos entre vereadores e oferece recursos administrativos para acompanhamento de pesquisas, visualização de resultados e exportação de dados.

## Funcionalidades

- **Votação interativa:** confrontos entre vereadores, com continuidade do vencedor.
- **Gerenciamento de pesquisas:** acompanhamento de pesquisas concluídas e incompletas.
- **Dashboard administrativo:** indicadores e gráficos para visualização dos resultados.
- **Ranking:** consulta e organização dos resultados registrados.
- **Gerenciamento de vereadores:** administração dos participantes cadastrados.
- **Exportação para Excel:** geração de planilhas para análise dos dados.
- **Auditoria e logs:** consulta de registros e atividades administrativas.
- **Mecanismos de controle:** recursos de identificação de sessões e limitação de requisições.

## Tecnologias

- Python
- Flask
- HTML, CSS e JavaScript
- Chart.js
- OpenPyXL
- SQLite, conforme a configuração da aplicação

## Organização do projeto

A aplicação utiliza uma estrutura modular, com separação entre rotas, serviços, templates HTML e arquivos estáticos, facilitando a organização e a manutenção do código.

## Execução local

Instale as dependências:

```bash
python -m pip install -r requirements.txt
```

Execute a aplicação:

```bash
python app.py
```

Acesse `http://localhost:5000` no navegador.
